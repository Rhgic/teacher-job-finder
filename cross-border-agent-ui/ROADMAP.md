# Roadmap（未实现）

本文件仅描述后续方向；以下能力均不属于当前 V1。

## V2：单平台真实试点

- **真实 Shopify OAuth**：Authorization Code 流程、最小权限范围（`read_orders` / `read_fulfillments`），凭证交由部署环境的密钥管理，不落业务库。
- **回调验签**：启用 V1.1 中预留但未启用的回调路径，校验 Shopify HMAC 签名并拒绝重放。
- **只读订单同步**：先做单向拉取（订单 / 物流状态），不做任何写平台操作；写操作单独评审。
- Webhook 签名校验、事件幂等键。
- Redis 队列、重试和死信队列。
- 小范围真实店铺试点；真实写操作仍需业务与合规审批。

## V3：自助式多租户运营

- 自助租户管理、用量计费和多平台适配。
- 监控告警、评测与灰度发布。
- 数据保留、删除、访问控制和其他合规流程。
